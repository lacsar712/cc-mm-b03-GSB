# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 关注条

检查员可以把若干测点钉成关注条。关注名单、每点最新一笔、名单变更履历都存在服务端（`watches` / `watch_events` 表），浏览器本地只存登录令牌。

| 接口 | 权限 | 说明 |
|------|------|------|
| `GET /api/watchlist` | 登录可见 | 按名单返回各点当前最新浓度、状态、说明 |
| `POST /api/watchlist` `{site}` | 仅检查员 | 钉上，写一条“钉上”履历 |
| `DELETE /api/watchlist?site=` | 仅检查员 | 取下，写一条“取下”履历 |
| `GET /api/watchlist/history` | 登录可见 | 名单变更履历：谁、何时、增或删、测点名 |

未关注测点不会出现在关注条载荷里。旁观账号（viewer）能看关注条和履历，不能改名单。顶栏入口叫“关注条”。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 只钉回风巷：关注条载荷只有回风巷一个测点，浓度 1.4 报警。
5. 给东翼-12 再报一笔，关注条仍然没有东翼-12。
6. 给回风巷再报更高一笔（如 1.68），再拉关注条，回风巷浓度变成新值。
7. 履历里能看到 gasman 钉上回风巷的记录；viewer 能看关注条和履历，钉上/取下返回 403。
