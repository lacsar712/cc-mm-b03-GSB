# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

检查员可把关心的测点"钉上"关注条：名单与各点最新一笔均由服务端接口给出，名单的每次增删都在服务端留下履历（谁、何时、增/删、测点名）。顶栏入口为"关注条"，旁观账号只能看关注条与履历，不能改名单。

## 端口

|------|------|

| 接口 | http://localhost:8191 |

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 关注条：gasman 在"关注条"里只钉回风巷，关注条载荷只有回风巷（最新浓度 1.4、报警）。
5. 再给东翼-12 上报一笔，重新拉关注条仍无东翼。
6. 再给回风巷上报一笔更高的（如 1.7），关注条上回风巷浓度变成新值。
7. 履历里能看到 gasman 钉上回风巷的记录；viewer 能看关注条和履历，但钉上/移除均返回 403。

## 关注条接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/watchlist` | 登录 | 按名单返回各点当前最新浓度与状态，未关注点不出现在载荷里 |
| POST | `/api/watchlist` | 检查员(writer) | 钉上测点，写入一条 add 履历；重复钉上 409 |
| DELETE | `/api/watchlist/{site}` | 检查员(writer) | 移除测点，写入一条 remove 履历；不在名单 404 |
| GET | `/api/watchlist/history` | 登录 | 名单变更履历（谁、何时、增/删、测点名），倒序 |
